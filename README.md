# Need for Speed World - EA Launcher Remake

A **Classic EA style** launcher for *Need for Speed World* (Soapbox Race World).

It keeps the look and feel of the original NFS World launcher from EA and connects to community servers such as **NightRiderz**, **WorldUnited**, and others configured in the build.

## Download 

Use the **Releases** page on this repository and download the latest build package (ZIP).

Extract it to a folder of your choice (for example `C:\Games\NFS World Launcher`).

## What you need to run it

| Requirement | Details |
|-------------|---------|
| **OS** | Windows 7 SP1 or newer (Windows 10 / 11 recommended) |
| **Architecture** | 32-bit (x86) build – works on 64-bit Windows |
| **.NET Framework** | **4.7.2** or newer (4.8 is fine) |
| **Admin** | The launcher will ask for administrator permission (UAC) so game files can be updated and launched correctly |

### Install .NET Framework (if needed)

Most Windows 10/11 PCs already have it. If the launcher does not start:

1. Install **.NET Framework 4.7.2** or **4.8**:  
   https://dotnet.microsoft.com/download/dotnet-framework  
2. Restart Windows if prompted, then run `GameLauncher.exe` again.

Optional (only if the promo / web panel is blank):

- **Microsoft Edge WebView2 Runtime**  
  https://developer.microsoft.com/microsoft-edge/webview2/

## How to start

1. Extract the release archive completely (keep all files together).
2. Run **`GameLauncher.exe`**.
3. Accept the Windows security (UAC) prompt if it appears.
4. Choose or confirm the **game files folder** when asked.
5. Select a server, sign in, let it check/download files, then press **PLAY**.

## Notes

- This is a **community** launcher, not an official Electronic Arts product.
- *Need for Speed* and related marks belong to Electronic Arts Inc.
- You need a valid account on the private server you play on (register on the server’s website if you do not have one).

## Support

If the launcher does not open, check that **.NET Framework 4.7.2+** is installed and that you extracted **all** files from the release package.

## Servers in the launcher

CHICANE - EU (NIGHTRIDERZ - HORIZON: https://nightriderz.world/); CHICANE - US (WorldUnited OFFICIAL: https://worldunited.gg/) and APEX - EU (WorldEvolved: https://world-evolved.ru/en/)
